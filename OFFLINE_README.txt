싹둑 — 무료 녹음·영상 자동 분할 (오프라인 버전)
================================================

녹음·영상 파일을 원하는 길이로, 말이 끊기지 않는 조용한 지점에서 잘라 줍니다.
무료 · 광고 없음 · 회원가입 없음 · 인터넷 연결 필요 없음

■ 실행
  Ssakduk.exe 를 더블클릭하세요. 설치할 필요 없습니다.
  처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행] 을 누르세요.
  (개인이 만든 무료 프로그램이라 유료 인증서가 없어서 뜨는 안내입니다)
  처음 켤 때 몇 초 걸리는 것은 정상입니다.

■ 사용법
  1. 녹음·영상 파일을 창에 끌어다 놓거나, 가운데 영역을 눌러 선택합니다.
     (여러 파일이나 폴더째로 놓아도 됩니다)
  2. 최대 길이(분)와 조용한 곳 찾는 범위(초)를 정합니다. 기본은 5분 / 30초.
     → 각 조각은 4분 30초 ~ 5분 사이의 가장 조용한 지점에서 잘립니다.
  3. 영상 파일은 "영상 그대로 자르기" 또는 "소리만 뽑아서 자르기"를 고릅니다.
  4. [자르기 시작] → 끝나면 [결과 폴더 열기]

■ 결과
  원본 옆에 '원본이름_분할' 폴더가 생기고 번호 순서대로 저장됩니다.
    회의.m4a  →  회의_분할\회의_01.m4a, 회의_02.m4a ...
  다시 압축하지 않아서 음질·화질 손실이 없습니다.
