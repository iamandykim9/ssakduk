# 녹음 파일 분할기 (AudioSplitter)

녹음 파일을 **최대 5분 단위**로 자르는 Windows 프로그램입니다.

- 각 조각은 4분 30초 ~ 5분 사이에서 **가장 조용한 순간**을 골라 자르기 때문에 말이 중간에 끊기지 않습니다.
- 재압축 없이 잘라서 **음질 손실이 없고**, 1시간 20분짜리 파일도 10초 안팎이면 끝납니다.
- m4a, mp3, wav, flac, aac, ogg 등 대부분의 오디오 형식을 지원합니다.
- 결과: `회의.m4a` → `회의_분할\회의_01.m4a`, `회의_02.m4a` …

## 다운로드

[**AudioSplitter.exe 내려받기**](https://github.com/iamandykim9/audio-splitter/releases/latest/download/AudioSplitter.exe)

설치 없이 바로 실행됩니다. 처음 실행할 때 Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르세요.

## 사용법

1. 프로그램을 열고 녹음 파일을 창에 끌어다 놓거나, 가운데 영역을 클릭해 선택합니다.
2. 필요하면 최대 길이(분)와 조용한 곳을 찾는 범위(초)를 바꿉니다.
3. **자르기 시작**을 누르고, 끝나면 **결과 폴더 열기**로 확인합니다.
